**Must (from prize text / research notes):**

Also note 0G workshops early in the event; show up if possible.

## World — World ID Agent Pass ($5k, places $2.5k / $1.5k / $1k)

**Why us:** agent that needs a human for meaningful moments (over budget, age-restricted).

**Must:**

- Official World ID Agent Pass integration
- Full journey: request → user completes → backend validates → protected action
- A denied / expired / cancelled path where the action does **not** happen
- Validate on the server; never trust the client alone
- Short integration debrief (time to first success, friction, one top improvement)

Proofs may be mocked at the event; do not treat them as production identity.

IDKit is a related World prize if we lean hard into credential choice (e.g. age). Agent Pass is the primary fit.
